# Create and edit custom fields

Found via the custom-fields hub page (use-custom-fields-quickbooks-online/L99B82F1d), which has no instructions of its own.

## Purpose / when to use
Track business-specific details (sales rep, customer type, vendor ID, PO number, project manager, industry data) on sales forms, purchase orders, expense forms, and customer/vendor profiles, and report on them.

## Steps in QBO
From settings:
1. Gear > Custom fields.
2. Add custom field (or Add field if some already exist).
3. Name.
4. Data type: Text and number, Number only, Date, or Dropdown list (enter the list choices for a dropdown).
5. Category: Customer (profiles), Vendor (profiles), Transaction (sales/purchase forms) or Project.
6. Tick the forms it should appear on.
7. Tick Print on form if customers/vendors should see it on the printed/emailed form.
8. Save.

Manage (on the custom fields page):
- Edit (Actions column): change name, forms or print setting > Save.
- Inactivate: arrow next to Edit > Make inactive > Yes.

From a form: open the form > the gear at the top of the form (not the main navigation gear) > Custom Fields section > + Add custom field, or the pencil to edit, or Manage custom fields.

From a profile: All apps > Customer Hub > Customers & leads > open the customer or vendor > Edit > Custom fields tab > + Add custom field or Manage custom fields > close > Save the profile.

## Prerequisites and plan limits
- Enhanced custom fields require QBO Advanced.
- Up to 12 active custom fields per form type (invoice, estimate, PO, expense, bill, etc.) and per profile type (customer, vendor).
- At most 3 fields per form type can have Print on form turned on.
- Purchase orders must be switched on before custom fields can be used on them.

## Pitfalls
- Editing a field changes it everywhere it is used, not just on the current form.
- Inactivating keeps past data on old forms; the field just stops appearing on new ones.

## How to verify
Check the custom fields page for the right category and forms; open an assigned form to see the field; preview the form if Print on form is on.
