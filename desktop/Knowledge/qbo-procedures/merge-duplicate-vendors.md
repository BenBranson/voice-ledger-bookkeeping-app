# Merge duplicate vendors

## Purpose / when to use
Combine two profiles for the same vendor. All past transactions move from the duplicate to the profile you keep, and the duplicate is made inactive.

## Steps in QBO
1. All apps > Expenses & Bills > Vendors.
2. Open the vendor profile you want to get rid of (the duplicate).
3. Edit dropdown > Merge contacts.
4. In the Into dropdown, choose the vendor profile to keep.
5. Merge contacts to finish.

## Prerequisites and plan limits
- You need edit access to vendor profiles.
- Know the company name and display name of the profile you are keeping.

## Pitfalls
- Choose carefully which profile survives. There is no undo; getting the merged vendor back means recreating the profile by hand.
- Start from the profile you want to remove, not the one you keep.

## How to verify
The duplicate shows as deleted/inactive, and its past transactions now appear under the kept vendor.
