# Create recurring invoices and other transactions in QuickBooks Online

## Purpose / when to use
Save a template for any transaction that repeats (invoices, estimates, expenses, rent, loan payments) to save time and reduce errors. Eligible invoices can also collect payment automatically through QuickBooks Payments (merchant services).

## Steps in QBO
New template:
1. All apps > Accounting > Recurring transactions > New.
2. Choose the transaction type > OK.
3. Enter a Template name.
4. Choose a Type:
   - Scheduled: created and sent automatically with no changes (e.g. rent, loan payment).
   - Reminder: QuickBooks reminds you; you edit and send it (e.g. a utility bill that varies).
   - Unscheduled: no schedule; you use it manually when needed.
5. For Scheduled or Reminder, set the Interval.
6. Set options such as including unbilled charges, automatic emailing, and print marking.
7. If using merchant services, set Online Payment options.
8. Fill in the transaction details > Save template.

Use an unscheduled template: Recurring transactions > find it > Use (Action column) > complete the transaction.

Duplicate a template: Recurring transactions > Edit dropdown > Duplicate > rename it.

Make an existing transaction recur:
- Invoice: Manage (gear) > Scheduling > turn on "Make invoice recurring".
- Sales receipt, deposit, credit memo: Make recurring.

## Prerequisites and plan limits
Active QBO subscription on the new QBO experience. QuickBooks Payments is optional (only for automated customer payment).

## Pitfalls
- Invoices generated from recurring templates are saved as drafts; you must review and finalise them.
- An existing estimate cannot be converted into a recurring estimate; build a new recurring estimate.
- Review templates periodically so payment methods, prices and intervals stay correct.

## How to verify
Templates appear in the Recurring transactions list, where the type determines whether QuickBooks posts automatically, reminds you, or waits.
