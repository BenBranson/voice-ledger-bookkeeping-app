# Create and send customer statements

## Purpose / when to use
Remind customers what they owe and show their account activity.

Statement types:
- Balance forward: invoices, payments and the running balance for a period.
- Open item: every unpaid invoice from a start date forward.
- Transaction statement: every transaction in a date range.

## Settings
Settings > Account and settings > Sales > Statements: show each transaction on one line or with detail (e.g. finance charges). Save > Done.

## Steps in QBO
All apps > Customer Hub > Customers & leads > tick the customers > Batch action > Statement > choose Statement type > set Statement date, Start date and End date > check each customer's email > Save and send > review preview > Send.

## Pitfalls
- A statement is only produced for customers with activity in the chosen range.
- Sub-customers set to "Bill with parent" only appear on the parent customer's statement.

## How to verify / manage
The customer's Statements tab lists past statements (send, print, download, delete). Statements update if the underlying transactions change.
